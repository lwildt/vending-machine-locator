# Contributing

Kurzbeschreibung, wie man Beiträge leistet.

1. Stelle sicher, dass du den `development`-Branch verwendest:

```bash
git checkout development
git pull
```

2. Erstelle einen Branch (`feature/` oder `bugfix/`), implementiere, teste lokal.
3. Push zum Remote und öffne einen PR nach `development`.
4. Beschreibe in der PR die Änderungen, Testschritte und ggf. offene Punkte.

Tests: keine automatischen Tests im Repository (aktuell). Bitte manuell lokal prüfen.
